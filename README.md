In this repository we provide the codes and corresponding numerical results for the paper arXiv 2609.31863, "Indefinite causal order with output-signalling instruments". They're organized as follows:

Sec. VI.a - "Violation of LGYNI"; 
Sec. VI.b - "Process matrix parametrization";
Sec. VI.c - "State misalignment threshold";
Sec. VI.d - "Inequality violations".
